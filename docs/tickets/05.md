## What to build

用户集中配置常驻运行、剪贴板、代理、接管规则和下载展示，设置立即按既定边界影响实际任务。

## Acceptance criteria

- [ ] 关闭主窗口固定驻留托盘，保持下载与启用的监听；不提供关闭即退出开关，提供明确退出操作。
- [ ] 提供开机启动开关，验证各目标系统托盘与启动能力并记录兼容边界；重新启动仍须手动继续任务。
- [ ] 代理提供直连、系统代理、自定义地址，仅影响应用自身；正在下载任务沿用原配置，新任务和暂停后继续用新配置。
- [ ] 统一设置全局默认连接数、默认 3 个同时下载任务上限、提前下载、窗口显示及完成信息行为，并与实际任务联动。
- [ ] 提供独立的自动接管常用后缀、页面站点排除和自定义临时快捷键配置；浏览器侧执行由扩展任务交付。
- [ ] 剪贴板开关开启后按上述接管后缀匹配 HTTP/HTTPS URL 路径，忽略查询参数；命中打开信息对话框，普通网页及无后缀链接保持手动添加。
- [ ] 开关和配置持久保存；剪贴板行为遵守既有提前下载和队列规则。
- [ ] 通过真实下载验证代理切换、上限修改和显示设置，通过三平台检查验证托盘/监听；不把未测试平台写为已通过。
