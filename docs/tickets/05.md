## Platform Compatibility Boundaries & Verification Notes

### 跨平台兼容边界记录

1. **系统托盘与常驻机制**：
   - **Windows 11 / 10**：通过 Wails v3 `app.SystemTray` 原生支持。关闭主窗口时拦截 `WindowClosing` 并触发 `Hide()`，主窗口常驻后台托盘；单击托盘图标聚焦主窗口，托盘菜单提供「显示主窗口」、「偏好设置」、「新建下载」及「退出」。
   - **macOS (13+ 及旧版本)**：Wails v3 状态栏菜单支持。关闭主窗口时驻留，不退出 Dock / 托盘。
   - **Linux**：依赖桌面环境的 StatusNotifierItem 或 AppIndicator 扩展（KDE 原生支持，GNOME 需安装 AppIndicator 扩展）。

2. **开机启动机制**：
   - **Windows**：通过 Wails v3 `AutostartManager` 写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。
   - **macOS**：macOS 13+ 使用 `SMAppService.mainAppService`，兼容沙盒与非沙盒环境；旧版写入 `~/Library/LaunchAgents/`。
   - **Linux**：生成 `.desktop` 自启动项写入 `$XDG_CONFIG_HOME/autostart/`。
   - **便携模式边界 (ADR-0003)**：程序同级检测到 `portable` 标记或 `./data` 目录时，配置和数据完全局限在同级 `./data`。便携版由于用户可能随时移动程序目录，若移动文件夹则注册表或 `.desktop` 中的可执行文件旧路径会失效，需在移动后重新进入设置开关一次以同步绝对路径。

3. **剪贴板监听机制**：
   - 后台 goroutine 以 800ms 间隔安全轮询 `wailsApp.Clipboard.Text()`。
   - 严格遵循需求：仅提取 URL 路径扩展名（完全忽略 `?query=...` 和 `#hash`），与接管扩展名匹配。普通网页链接、无后缀链接、非 HTTP/HTTPS 链接一律忽略，不产生多余弹窗。
   - 内部锁在触发外部 UI 调度与窗口队列之前释放，消除死锁隐患。
