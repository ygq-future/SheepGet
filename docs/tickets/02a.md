## What to build

建立配置中心（Settings Center）作为全局偏好与运行规则的单一事实来源，落地便携版与安装版双轨数据存储，实现包含外观主题、强调色、重复链接策略、提前下载开关、并发上限及目录的配置模型、原子持久化与主窗口内嵌设置面板。

## Acceptance criteria

- [x] 落地 ADR-0003 双轨存储判定：启动时检查程序同级 `data/` 目录或 `portable` 标记文件，存在则进入便携模式，数据读写限定在 `./data`；否则进入安装模式使用系统标准用户目录，严格物理隔离无读写交叉。
- [x] 建立 Go `SettingsService`，管理 `config.json` 原子读写与线程安全并发访问，校验异常字段并安全回退默认值。
- [x] 建立初始配置 Schema：外观（主题模式 `system`|`light`|`dark`、强调色 `accentColor`）、下载行为（重复链接策略 `duplicateUrlPolicy`、提前下载 `preDownload`、并发上限 `maxConcurrentDownloads`、连接数 `defaultConnectionsPerTask`、默认目录与临时目录）。
- [x] 配置修改即时持久化并触发事件总线广播，供下载引擎及各活跃窗口热更新。
- [x] 前端建立全局配置 Store，将主题与强调色作为 CSS 变量注入根节点，实现无刷新即时切换。
- [x] 主窗口提供内嵌设置面板视图（可通过侧边栏/标题栏设置入口访问），支持查看与修改外观及下载行为配置。
- [x] 编写便携模式隔离、配置持久化校验及配置更新事件的测试用例，全量质量门禁通过。
