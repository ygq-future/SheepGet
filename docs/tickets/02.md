## What to build

### 1. 现状记录（初步实现已完成项，对应 commit `88ebf34`）

- 后端完成 `ProbeURL` 资源探测（文件名、大小、MIME 类型、Range 支持及 ETag 标识），明确拦截 403/404 等错误状态码。
- `Task.RequestHeaders` 全链路贯通，下载器探测、单流与分块请求均携带请求头上下文，支持鉴权续传。
- `CheckURLConsistency` 严格一致性校验与 `UpdateTaskURL` 自动恢复传输：在 ETag / Last-Modified 凭据匹配或零进度时安全续传，无可靠凭证时拒绝拼接并提示重新下载。
- 提前下载生命周期：确认时安全等待协程退出并原子移动分片/成品，进行中取消停止传输并保留分片供后续恢复，提前完成后取消保留完成态与文件。
- `CheckFileConflict` 统一序号命名规则（`stem (n).ext`），并在提前下载触发前实施同名冲突前置拦截。

### 2. 本阶段改造与目标形态

- **独立原生桌面辅助窗口**：彻底移除原单窗口内嵌 Modal，基于 Wails v3 `app.Window.NewWithOptions` 建立独立小巧的原生辅助窗口（SPA 路由 `/?window=fileinfo`）。主窗口常驻托盘时，外部下载触发仅唤起该独立窗口，主窗口保持隐藏；确认或取消该窗口绝不联动激活主窗口。
- **多任务队列管理与自由检视切换**：实现后端窗口队列控制器。短时间内由浏览器、剪贴板或多次点击并发触发多个下载请求时，统一由文件信息窗口承载；当有多条任务排队时，窗口顶部提供多任务快速切换控制器（上下条切换及进度指示），用户可自由在排队任务中切换查看并执行操作，前序任务确认或取消后无缝呈现后续任务。
- **配置中心全面联动**：全面接入 Ticket 02A 配置中心，继承默认单任务连接数。
- **重复链接策略四项闭环**：
  1. `prompt`（询问，默认）：弹出文件信息窗口并提供“查看已完成”、“继续覆盖”、“序号副本”三种选项；
  2. `skip_show_completed`（跳过并显示完成）：若已有已完成任务，唤起并定位到共享下载进度窗口（`/?window=progress`）的置顶完成区域，同时保持当前文件信息窗口打开不自动关闭；
  3. `continue_overwrite`（继续并覆盖）：唤起文件信息窗口确认保存信息，确认后对已有任务执行继续续传或重新覆盖下载；
  4. `numbered_copy`（序号副本）：唤起文件信息窗口并自动填充 `name (n).ext` 建议名称，确认后作为独立副本任务入队。

## Acceptance criteria

- [x] 文件信息窗口作为独立原生辅助窗口存在，加载 SPA 独立路由视图；主窗口驻留托盘时可独立唤起与关闭，主界面不夺焦或弹出。
- [x] 多个下载请求并发到达时，在后端窗口队列中有序管理；支持在窗口内自由切换查看并操作任意排队任务，前序任务确认/取消后平滑过渡展示。
- [x] 读取配置中心获取默认连接数，全局偏好设置统一管理下载运行策略。
- [x] 默认仅获取元信息不下载正文；信息探测失败明确显示未知且不阻断用户手动下载；未确认且无实际传输取消不留任务记录。
- [x] 全局重复策略为 `skip_show_completed` 时，激活共享下载进度窗口的完成信息区域，同时保持文件信息窗口开启供用户进一步操作。
- [x] 全局重复策略为 `prompt` 时，提示重复并提供“查看已完成”、“继续覆盖”、“序号副本”三种选择并正确执行分支动作，选择“查看已完成”时保持文件信息窗口开启。
- [x] 全局重复策略为 `continue_overwrite` 或 `numbered_copy` 时，唤起文件信息窗口供用户确认保存位置与名称。
- [x] 目标目录已存在同名文件（含关联序号文件）时实施前置拦截，用户明确确认覆盖或添加序号后方可落盘传输。
- [x] 继承并保持过期链接更新（含请求头编辑）与严格一致性续传的完整行为。
- [x] 编写独立窗口唤起调度、多任务队列切换与重复策略分支的测试，全量质量门禁通过。
