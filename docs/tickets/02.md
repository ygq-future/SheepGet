## What to build

让用户在正式下载前查看资源并修改名称、目录和单任务连接数，完整处理提前下载、取消、重复任务与链接更新。

## Acceptance criteria

- [ ] 默认展示名称、类型、大小、来源与保存位置，允许改名、改目录和单任务连接数；信息不可得显示未知且可继续。
- [ ] 默认仅获取必要信息，不持续下载正文；未确认且没有实际下载时取消不留下任务。
- [ ] 提前下载开关开启时仍显示对话框并允许编辑保存信息，传输遵守任务上限；确认后成品使用最终名称和目录。
- [ ] 提前下载进行中取消会停止传输并保留暂停任务；提前完成后确认可直接进入完成展示，不制造重复下载。
- [ ] 对提前完成后再取消的终态边界形成明确状态处理，保留正确数据；若必须改变已确认产品语义，说明影响后再实施。
- [ ] 重复链接按完整 URL 相同判断，默认询问，提供继续已有任务、重新下载、序号副本及已完成展示等已确认策略；新下载另检查目标同名冲突。
- [ ] 同名文件默认询问并支持覆盖或添加序号；覆盖须基于用户明确选择，继续任务不误建副本。
- [ ] 支持更新过期链接及所需请求信息；确认同一文件后续传，无法确认一致性提示重新下载。
- [ ] 用任务公开操作和文件结果验证未知信息、预下载取消、改名改目录、冲突及过期链接恢复；预留清晰度已固定的媒体信息展示。
