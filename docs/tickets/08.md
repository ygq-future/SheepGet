## What to build

提供可安装的 Windows、macOS、Linux 版本及配套扩展，完成从安装到文件/媒体成品的端到端验收。

## Acceptance criteria

- [ ] 提供各目标平台安装产物和明确的系统/架构兼容矩阵；记录实际验证环境，不用交叉编译成功代替运行验证。
- [ ] 安装包含配套扩展文件及开发模式加载说明；验证首次安装、更新后扩展位置与重新加载、浏览器交接和应用唤起。
- [ ] 核对 Native Go 默认媒体能力及安装包/安装后实际体积，用户无需额外安装必需 FFmpeg 即可处理已支持组合。
- [ ] 按母规格 A01–A19 执行整体验收，覆盖完整下载、重启手动恢复、代理、分类、提前下载、扩展失败和媒体重试。
- [ ] 验证共享窗口的视觉风格、动画、限高滚动与操作稳定性，托盘、剪贴板、开机启动和文件打开在兼容矩阵内正常工作。
- [ ] 汇总服务器时间、扩展权限、媒体兼容性、慢块性能测试和状态边界的验证结论；未通过项不得标为完成。
- [ ] 发布可复现的验收结果和已知限制；不擅自扩大限速等尚未定范围，不改变已确认产品规则。
