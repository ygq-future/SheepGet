## What to build

用户通过设置页配置分类后缀、保存目录、临时目录及文件时间，并在真实下载中得到对应保存结果。

## Acceptance criteria

- [x] 预置文件、视频、音频、图片、压缩包、软件分类，支持配置后缀和目录；未匹配进入文件分类。
- [x] 支持创建自定义分类，新建置顶，可拖动排序；先按自定义列表首个匹配，再匹配内置分类。
- [x] 后缀规则允许重叠，自定义 rar 规则不会删除内置压缩包的 rar；删除自定义规则后可回退内置匹配。
- [x] 分类只决定目录，与自动接管类型完全独立；文件信息对话框的手动目录优先。
- [x] 临时目录可配置并在真实任务中使用，正确转存成品，验证不同磁盘/文件系统下失败时保留可恢复数据。
- [x] 先核实服务器时间字段及三平台文件时间能力，再提供准确的时间选项；不将 Last-Modified 静默解释为创建时间，能力偏差需明确呈现。
- [x] 设置持久保存；通过重叠后缀、排序、手动目录优先、临时文件及时间可用/不可用场景验收。
