## What to build

所有下载任务共用一个独立进度窗口，追加新任务并在原区域展示完成信息，避免多窗口堆积。扩展配置中心 Schema，新增窗口显示与完成信息相关配置并接入主窗口设置面板。

## Acceptance criteria

- [ ] 确认下载后按显示设置打开单一共享窗口；后续任务追加而不是新增独立窗口，关闭窗口不停止下载，可从主列表重新查看。
- [ ] 展示各任务实时下载区块与进度，下载中按进度降序实时排序；已完成区域固定顶部并保持操作可用。
- [ ] 窗口具备高度上限和内部滚动，采用已确定的视觉风格及流畅过渡。
- [ ] 完成后原区域转为完成信息，只有完成区域提供打开文件和文件夹操作；手动关闭区域不删除主列表记录。
- [ ] 配置中心扩展 `download` 字段：`showProgressWindow`（默认开启）、`keepCompletedInfo`（默认开启）、`autoRemoveCompletedOnOpen`（默认关闭），并在主窗口设置面板中提供统一配置入口。
- [ ] 关闭保留完成信息（`keepCompletedInfo: false`）时完成后移除区域；关闭自动显示（`showProgressWindow: false`）时任务完成也不主动弹出窗口。
- [ ] 等待、暂停、未知大小、处理和失败状态可理解地展示，明确其排序而不破坏完成顶部及下载中降序规则。
- [ ] 预留处理失败和仅重试处理的交互边界；真实媒体处理流程在 HLS 任务接入，不以模拟处理作为媒体功能完成。
- [ ] 通过多任务交互验证唯一窗口、排序、滚动、完成操作、开关和提前完成场景。
