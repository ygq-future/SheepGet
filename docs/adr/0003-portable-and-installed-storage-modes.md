# 支持安装版与便携版双轨数据存储模式

SheepGet 需要同时满足普通桌面用户的标准安装体验与极客/离线用户的免安装便携使用体验。为确保配置中心、下载任务库与临时文件的物理隔离与平滑迁移，确立双轨数据存储判定机制。

## 决策背景

1. 操作系统常规安装应用应遵循平台规范，避免向程序目录写入运行时数据（在受保护目录如 `Program Files` 下会导致写入权限拒绝）。
2. 用户在 USB 闪存盘、不同电脑间移动使用，或进行多实例隔离测试时，期望应用将全部配置文件、任务持久化文件和临时数据置于程序同级目录，实现真正“即拷即用、删目录即卸载”。

## 判定与路径解析规则

数据根路径（`DataDir`）由 Go 后端在启动阶段最早解析，生命周期内固定：

1. **便携模式检查**：
   - 检查程序可执行文件所在目录下是否存在名为 `portable`（空文件或无后缀文件）或已存在的 `data/` 目录。
   - 若命中上述任一标志，应用判定为**便携模式**，统一将 `DataDir` 设定为程序目录下的 `./data`（若不存在则自动创建）。
2. **标准安装模式回退**：
   - 若未检测到便携标志，则判定为**安装模式**，按各操作系统标准目录组织：
     - Windows: `%APPDATA%\SheepGet`
     - macOS: `~/Library/Application Support/SheepGet`
     - Linux: `$XDG_DATA_HOME/sheepget`（回退为 `~/.local/share/sheepget`）
3. **数据目录布局**：
   - `DataDir/config.json`：配置中心全局持久化配置。
   - `DataDir/tasks.db`（或 JSON 数据库）：下载任务元数据与分块状态。
   - `DataDir/temp/`：默认临时文件存放目录（可被配置中心覆盖）。
   - `DataDir/logs/`：应用程序运行时日志。

## 权衡与约束

- **禁止跨模式静默混用**：程序只在当前模式的 `DataDir` 读写，不自动向另一目录静默读取或迁移，防止数据冲突。
- **便携模式权限提示**：便携版运行在无写权限的只读路径时，启动阶段应明确拦截并给出友好错误，杜绝静默失败。
