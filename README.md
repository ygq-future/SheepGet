SheepGet 是一款面向 **Windows、macOS 和 Linux** 的现代化桌面下载工具。它致力于提供克制精致的界面设计、极速稳定的多线程下载体验以及深度的浏览器流媒体嗅探与下载接管能力。

---

## 功能亮点

### ⚡ 高速多线程与自适应防封引擎

- **自适应动态并发探测**：根据实时吞吐与目标服务器响应动态调节分块并发连接数，充分利用可用带宽；
- **智能拖尾慢区块协助**：自动感知长尾慢区块并动态多通道分流抓取，大幅消除单连接限速引发的长尾等待；
- **429 / 503 限速智能回退**：命中服务端频控限速状态码时自动触发指数退避与分流熔断，保护网络连接免遭封禁；
- **重定向落地 URL 锁定**：探测阶段自动解析锁定最终落地 URL，后续并发分片统一请求，杜绝 CDN 节点漂移引发分片版本不一致；
- **RFC 标准与 URL 参数文件名提取**：全面兼容 RFC 5987 / RFC 6266 `filename*=UTF-8''...` 国际化编码，自动解析 URL 查询参数中的动态文件名；
- **稳健断点续传与致命错误熔断**：支持暂停、继续与网络波动自动重试；支持过期直链原地更新续传；对 401/403/404 等致命错误立即反馈熔断。

### 🎬 原生点播流媒体下载（免外部 FFmpeg）

- **Native Go 纯原生媒体处理**：无须在操作系统中安装或随身打包数百兆外部 FFmpeg 运行时，极速轻量；
- **无损封装标准 MP4**：自动解析 HLS 点播资源与 TS / fMP4 切片，精确对齐音视频时间戳，无损封装为通用 MP4 视频；
- **播放器快捷悬浮条**：配套扩展自动关联网页播放器并在右上角外侧停靠小巧悬浮条，鼠标悬停直接滑出清晰度菜单；
- **清晰度预选与多变体精准归档**：进入下载前直观展示各画质预估文件大小；多清晰度变体精准去重，支持按需独立归档。

### 🧩 双核浏览器深度无缝协同（Chrome & Edge）

- **智能规则接管**：按文件类型后缀与规则自动接管下载；桌面端未就绪时平滑交还浏览器原生下载；
- **DOM 点击超前捕获**：在浏览器原生下载触发前精准置换上下文，支持按住快捷键临时强制接管或暂停接管；
- **源网页 URL 与防盗链 Referer 补全**：优先读取主标签页真实地址栏 URL 随任务原子化持久化，自动补齐防盗链请求上下文；
- **资源嗅探面板**：扩展工具栏图标一键查看并筛选当前页面已捕获的音频、视频与流媒体资源。

### 🤖 自动化直连 API 与 AI Agent 生态集成

- **RESTful 直连下载 API**：暴露标准 `POST /api/v1/tasks` 端点，支持无缝接收外部自动化脚本与第三方工具的任务推送；
- **双轨安全鉴权**：在动态会话令牌（Session Token）基础上提供静态 API Key 支持，满足持久化脚本与工具集成的鉴权需求；
- **OpenAPI 3.1 规范暴露**：挂载 `GET /api/v1/openapi.json`，方便各类 API 工具与 SDK 生成器直接导入契约；
- **内置 AI Agent Skill**：内置 Agent 工具包，支持动态密钥同步与一键目录定位，AI 助手可直接操作桌面端下载引擎。

### 🪟 专注精致的多窗口交互体验

- **独立文件信息窗口**：触发下载时唤起独立轻量原生辅助窗口，不抢占主工作区焦点；支持探测中提前确认入库与后台纠偏；
- **共享下载进度窗口**：多任务共用一个紧凑进度窗口，支持进度降序排列与内部限高滚动；支持主列表与进度窗操作双向控制联动；
- **任务净下载耗时与高平滑 ETA**：剔除暂停与排队等待的真实传输耗时统计，结合滑动窗口瞬时速率给出稳健平滑的剩余时间预估；
- **系统托盘静默驻留**：主窗口关闭后最小化静默驻留托盘，后台任务与监听保持稳定运行。

### 📁 智能分类迁移、便携模式与自动更新

- **分类目录动态继承**：分类目录自动继承全局默认下载目录，调整默认位置时分类子目录动态随之调整；
- **文件一键迁移向导**：变更目录时自动唤起迁移向导，同卷毫秒级原子重命名，跨卷安全校验转存并保留进度；
- **全平台自动更新**：直连 GitHub Releases 智能检测匹配最优安装包；Windows 便携版支持退出后秒级原地热替换与自动重启；
- **绿色免安装便携支持**：数据配置与扩展跟随程序同级目录，即拷即用。

## 浏览器配套扩展与安装

SheepGet 提供随程序附带的浏览器配套扩展（Manifest V3），支持 Google Chrome 与 Microsoft Edge。

### 1. 扩展快速加载（三键一拖）

SheepGet 桌面端内置扩展定位与地址接力功能，通过以下步骤即可完成加载：

1. **进入扩展页面**：在 SheepGet 主界面打开「设置」→「接管与规则」，点击「**打开 Chrome 并复制地址**」（或「打开 Edge 并复制地址」）。程序会唤起浏览器并把扩展管理页地址写入剪贴板，切到浏览器地址栏按 `Ctrl+V`、`回车` 即可进入；随后开启页面右上角的「**开发者模式**」。
2. **定位扩展目录**：在设置面板中点击「**定位扩展目录**」，系统文件管理器将自动打开并高亮配套扩展文件夹；
3. **拖拽完成安装**：直接将高亮的扩展文件夹**拖入浏览器扩展页面**，即可完成加载。

> 扩展管理页属于浏览器特权页面：Chromium 会丢弃命令行传入的 `chrome://` / `edge://` 地址，也禁止网页内容导航过去，因此该页面只能由用户在地址栏粘贴进入。

加载成功后，可在浏览器扩展列表中核对 **SheepGet Integration Module**，其扩展 ID 固化为：

```text
oediboaeofmnlkgcjhnpfnngphkjooam
```

> **提示**：也可以在扩展管理页点击「加载已解压的扩展程序」，直接选中「定位扩展目录」已高亮的那个文件夹；从源码构建的开发者执行 `bun run --cwd extension build` 即可生成构建产物。

### 2. 与桌面端通信与自动发现

无论是便携版还是安装版，SheepGet 均统一采用本地安全 HTTP 与 WebSocket 环回通道与配套扩展通信：

- 桌面端启动时在本地安全端口（默认 `9248`，遇冲突自动顺延）开启服务通道并生成会话认证令牌；
- 浏览器扩展通过本地 HTTP 自动探测并自愈连接，在扩展弹窗中可实时查看当前连接状态与生效端口；
- 当桌面端未启动时，浏览器正常保留原生下载行为，待桌面端就绪后扩展自动恢复接管；
- 浏览器扩展与桌面端发版完全解耦，用户亦可在客户端「设置」→「关于与更新」中**独立检测扩展版本并一键热更新**。

## 自动化 API 与 AI Agent 集成

SheepGet 内置轻量级本地开放接口，支持外部脚本或 AI Agent 调度下载：

1. **开启 API 访问**：在「设置」→「高级与开发者」中查看本地服务端口，并可配置长期有效的「静态 API Key」；
2. **OpenAPI 规范**：桌面端运行后，可直接访问本地 OpenAPI 契约文档：
   ```text
   http://127.0.0.1:9248/api/v1/openapi.json
   ```
3. **创建下载任务示例**：
   ```bash
   curl -X POST http://127.0.0.1:9248/api/v1/tasks \
     -H "Content-Type: application/json" \
     -H "X-SheepGet-Token: your_static_api_key" \
     -d '{
       "url": "https://example.com/file.zip",
       "filename": "custom_name.zip",
       "directory": "D:/Downloads"
     }'
   ```
4. **内置 Agent Skill**：在「设置」中点击「定位 Agent Skill 目录」，可直接将内置技能导入 Claude Code、Cursor、Windsurf 等 AI Agent 工具中协同使用。

## 打包分发与成果输出

执行跨平台打包命令，自动就绪构建工具集（NSIS / WiX），构建桌面主程序、浏览器扩展并生成便携版、NSIS 安装程序与 MSI 安装包：

```bash
bun run package
```

打包产物**统一输出至 `build/dist/`**，命名规范与发布矩阵完全对齐：

```text
build/dist/
├── SheepGet_1.0.9_x64-setup.exe                  # Windows x64 NSIS 安装程序（带向导与快捷方式）
├── SheepGet_1.0.9_windows-x64-portable.zip       # Windows x64 绿色免安装便携包（即拷即用）
├── SheepGet_1.0.9_x64_en-US.msi                  # Windows x64 MSI 企业静默安装包
├── SHA256SUMS.txt                                 # 所有分发资产的 SHA-256 校验和
└── extension/                                     # 预编译配套浏览器扩展目录
```

## 源码构建与运行

如果您希望自行从源码构建或参与开发：

### 前置环境

- **Node.js**：`24.21.0` 或更高版本
- **Bun**：`v1.4.2` 或更高版本
- **Go**：`1.27.1` 或更高版本
- **CGO 编译环境**：Windows 推荐 MinGW-w64 (GCC)，Linux 需安装 `libgtk-4-dev`、`libwebkitgtk-6.0-dev` 与 `pkg-config`，macOS 需安装 Xcode 命令行工具。

### 1. 初始化项目

克隆仓库后，在根目录执行初始化脚本以安装依赖和工具链：

```bash
node scripts/bootstrap.mjs
```

### 2. 本地开发与启动

启动开发热重载服务器（Go 后端与前端界面联动）：

```bash
bun run dev
```

### 3. 代码质量门禁

提交前运行质量门禁确保所有校验与测试通过：

```bash
bun run quality
```
